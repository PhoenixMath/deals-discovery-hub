About

Deals Discovery Hub is a personal content-management project focused on discovering and sharing useful product deals and recommendations.

The project is designed to help create, organize, and publish original product-discovery content to Pinterest boards managed by the account owner.

Pinterest Integration

Deals Discovery Hub Automation may integrate with the official Pinterest API using Pinterest OAuth 2.0 for authorized content-management functionality, including managing Pins and boards belonging to the authenticated user.

The application does not request or collect Pinterest passwords or browser session credentials.
